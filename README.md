# NEON AURA AR

## Project Overview

NEON AURA AR is an immersive browser-based augmented reality experience that uses your webcam and hand tracking to create a neon, audio-reactive visual world. By detecting hand gestures in real time, the app transforms your movements into glowing particles, electric ripples, and animated light effects for a futuristic and interactive experience.

This project combines:
- Real-time hand tracking with MediaPipe
- Full-screen animated visuals and neon effects
- Gesture-based interaction such as pinch detection
- Audio-reactive sound and lighting effects
- Multiple visual themes for different moods

---

## How to Install & Run

### 1. Open the Project
Open the project folder in your preferred code editor, such as Visual Studio Code.

### 2. Run the Web Page
You can run the app in either of these ways:

- Open the file directly in your browser:
  ```bash
  index.html
  ```
- Or use a live server extension (recommended), such as Live Server in VS Code.

### 3. Allow Camera Access
When the app opens, it will request camera permission. Allow access so the hand-tracking feature can work properly.

### 4. Start the Experience
Click the button labeled "Enter Experience" to begin the interactive visuals.

> Note: The project uses online CDN libraries, so an internet connection is required for the MediaPipe scripts to load correctly.

---

## Features

- Real-time webcam-based hand tracking
- Neon particle and glow effects
- Gesture detection including pinch interactions
- Audio-reactive sound effects and hum modulation
- Multiple visual themes such as Rainbow, Cyberpunk, Lava, Ocean, and Galaxy
- Responsive full-screen experience for desktop and mobile browsers
